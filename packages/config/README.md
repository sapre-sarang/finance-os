# packages/config

Shared development tooling configuration for the React/TypeScript frontend
and Python backend (for example TypeScript, ESLint, formatting, linting, and
type-checking settings).

**Status:** empty — not yet scaffolded.

Goal: keep tool settings consistent across `apps/web`, `apps/api`, and
`packages/*`. Runtime settings are defined separately in the root
`config.example.yml`; credentials belong in `.env`.
